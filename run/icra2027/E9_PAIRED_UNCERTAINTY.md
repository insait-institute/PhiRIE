# Source-bound paired uncertainty table

The existing `robo.eval.paper_pipeline` accepts an optional
`agentic_paired_uncertainty: {path: <JSON>, sha256: <digest>}` in a
`preliminary_audit` config. It requires the complete 50-scene independent E3
completion audit to authenticate that exact source. It does not calculate or
resample any metric.

The full E3 producer predeclares four contrasts and four established metrics.
All sixteen rows transfer into `sources/agentic_paired_uncertainty.{json,csv}`
and `generated_tables/agentic_paired_uncertainty.tex`. Every displayed count,
difference, and interval endpoint has an exact JSON field in the claim ledger.
The original main tables are byte-identical with or without this option.

Coverage includes all 1871 planned jobs. Geometry and construction-probe
comparisons have common accepted support, with separate paired-job and supported
scene counts. Fewer than two supported scenes produces no interval, retaining
nulls and the contrast row. Intervals describe scene-cluster variation; they
provide neither seed replication nor multiplicity-adjusted significance nor an
independent physical validation. All claim/paper-ready flags stay unpromoted.

Reproduce the formatter checks:

```bash
python -m pytest -q tests/test_paper_paired_uncertainty.py tests/test_paper_pipeline_audit.py tests/test_paper_engineering_appendix.py
```

For actual publication, reserve a new E0-bound paper freeze after all E3
construction and independent evaluation outputs pass their existing audits,
then invoke `python -m robo.eval.paper_pipeline --config <new-config> --out
<new-freeze>/paper_tables --paper-root <paper-checkout>`. No full-cohort values
or uncertainty table have been generated by this implementation smoke.

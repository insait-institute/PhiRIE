01 — THE IDEA

A room is more
than its appearance.

A simulator needs objects with metric geometry, contact surfaces, and visual identities that stay connected during motion. PhiRIE builds these pieces through evidence-guided construction.

06 — THE RESEARCH

Making rooms
simulatable.

Evidence-driven real-to-sim connects candidate construction with interaction evaluation. The manuscript separates construction quality, coverage, and success under a declared reconstruction scope.

Read manuscript snapshot ↗Get v2.0.1 ↗

The supplied manuscript snapshot retains the earlier project name, SimAnyRoom. The code repository requires access.

How to read the demonstrations and results +

The gallery uses existing research artifacts. Scene images include training-view diagnostics and native synthetic LIBERO observations. Some construction examples use GT assistance. Coverage, held-out quality, and complete-room collision accuracy are distinct questions.

The live physics sandbox uses reconstructed meshes with browser-side Rapier dynamics and simplified convex colliders. The robot demo replays recorded MuJoCo states from a scripted cup push; it does not run a learned policy or establish grasp success. Web previews use reduced geometry and color detail. See the asset manifest for source identities, transformations, and checksums.

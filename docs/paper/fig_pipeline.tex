\caption{\name\ overview. A single training-free discovery stage emits one
mesh-vertex set per object and is consumed \emph{twice}: the physics branch
(left) builds a simulatable asset, and the appearance branch (right) erases
the same object from the background splat so the twin stays photorealistic
after objects move. Ground-truth instance annotations, when available,
substitute at exactly the discovery output contract, so every downstream stage
runs identically in both modes---which is what makes the ablation ladder of
Sec.~\ref{sec:ladder} a measurement of supervision rather than of two different
pipelines. Dashed arrows are the two feedback paths: the registered asset
contributes volume the scan never captured to the removal set, and verification
failures return as a re-processing worklist.}
\label{fig:pipeline}

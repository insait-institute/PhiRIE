# Paper source (snapshot)

The **live editing home of the paper is
[github.com/RunyiYang/SimAnyRoom](https://github.com/RunyiYang/SimAnyRoom)**,
kept as its own repository so it can be imported into Overleaf directly
(paper files at the repo root). Edit there; treat this copy as a snapshot
kept alongside the code.

- `root.tex` — extended version with appendices (main document)
- `conference.tex` — 8-page ICRA cut, same `body.tex`/`preamble.tex`
- `bash build.sh` — builds both PDFs with latexmk (cluster TeX Live module)

Note: in this paper, *SimFoundry* always refers to the cited prior system
(arXiv:2606.28276), never to this codebase — do not rename those mentions.

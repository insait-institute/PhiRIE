# PhiRoom v2.0.0

This release builds on main commit `394fb8ee` and adds modular feature interfaces and a pinned PhiView integration.
The package metadata is `phiroom==2.0.0`. PhiView remains independently versioned at
v0.2.0, commit `77d5999a7d659b55f6f214685923ccf51e6cfbd7`.

## Contents

- Sixteen module contracts with independent actions, runtime routing, pure command
  planning, composable pipeline recipes and fail-fast execution receipts.
- Six SimFactory adapter packages preserving the existing backend calls.
- A locked uv control environment, module contribution branches, CPU tests and
  [contribution workflow](../../CONTRIBUTING.md).

- Existing observation-to-simulation construction, model bridges, rendering, simulator
  export, evaluation and final-experiment tooling from PhiRoom main.
- The `integrations/phiview` Git submodule, with ten documented pipeline blocks and four
  uv lockfiles for CPU development, studio rendering, inference and generation.
- A root launcher and [setup guide](../PHIVIEW.md), including the pinned interactive
  backend API compatibility requirement.

The full source ZIP contains the exact parent source plus the pinned submodule source,
with no Git metadata, local environments or untracked model/data caches. Existing tracked
historical experiment receipts remain part of the source snapshot. These receipts are not
new experiments performed for v2.0.0. A release manifest identifies both commits and
SHA256SUMS verifies the downloadable assets.

## Validation boundary

Release validation covers the repository's non-launching final-experiment CPU preflight,
the PhiView CPU/backend contracts, recursive submodule checkout, package version and
archive integrity. Exact outcomes are retained in the attached validation receipt.
No new GPU experiment or browser benchmark is implied. The earlier PhysicalView H200
checks belong to its own recorded source/runtime combination.

The account's hosted GitHub Actions budget was exhausted during the preceding release.
Local checks are recorded explicitly; unavailable hosted jobs must not be described as
passing. The release uses the existing separate runtime environments described in
[ENVIRONMENTS.md](../ENVIRONMENTS.md); installing the lightweight Python package does
not install every GPU backend or download model weights.

Scientific status remains governed by [FINAL_EXPERIMENTS.md](../../FINAL_EXPERIMENTS.md).
Active research branches and uncommitted project-overview work are preserved. This release
does not assert completion of the paper campaign, general robot manipulation, or clean
scene-inpainting quality.

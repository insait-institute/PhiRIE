# PhiRIE v2.0.1

PhiRIE (From Photorealistic Reconstruction to Interactive Environments) is the
current project name. The repository is `RunyiYang/PhiRIE`; the Python distribution
and existing commands remain `phiroom==2.0.1`, `phiroom`, and `simfactory`.

## Changes

- Consolidate development on `main`, integrating the published generator comparison
  at `575eab337b74fa8b8d8ef2bca39c94cde64f566c` on top of the existing release line.
- Incorporate the primary checkout's 125 previously uncommitted migration edits,
  resolve the Gaussian training launcher conflict without losing its multi-phase
  behavior, and migrate additional executable defaults and corresponding tests.
- Synchronize package, CLI, control environment and lockfile versions at 2.0.1;
  declare PyYAML so the installed `simfactory` command works in a clean environment.
- Keep PhiView pinned at `2b7a01505d84d09e925c0d8b77ef61bfd7151b8f`.
- Replace redundant paper/harness workflows with one read-only reporting workflow;
  remove CI jobs that committed status markers or one-time integration patches.
- Add a locked, optional CPU regression dependency group, isolate optional model
  imports, replace an untracked quaternion shim with SciPy and tested scalar-first
  conventions, and make temporary test files and Unix sockets
  safe in independent checkouts.
- Ignore local worktrees, review-asset symlinks, build/cache products and local
  credentials. Limit default pytest discovery to `tests/`.
- Record the frozen-fields lock transition with its original hash and the reason:
  storage-path migration. Control, camera, action and metric definitions are unchanged.
  Resolve the exact approved legacy public-data root to its current location while
  retaining and validating the frozen declarations and source hashes.

## Branch and data preservation

The initial audit found 439 local branches, 234 remote-tracking branch references,
466 existing worktrees, and two worktrees with tracked edits. Branch consolidation
preserves the original tips in local `refs/archive/pre-v2.0.1/` references and in
`PhiRIE-pre-v2.0.1-history.bundle`. The bundle is a recovery archive, not a second
supported code line. Experimental tips not included in the release base are
identified in `branch-inventory.json`; retaining them does not mark them as merged.

Existing worktree directories remain at their original commits with detached HEADs;
the main working checkout advances to `main`. The studio worktree's 61 tracked edits
remain in place. The primary migration edits are incorporated into this release.
Datasets, checkpoints, outputs, demonstrations and historical evidence are retained.
Uncommitted-worktree patches and the complete local audit are retained under
`results/release-v2.0.1/audit/` in the consolidated PhiRIE workspace.

To inspect an archived tip without creating another branch:

```bash
git bundle verify PhiRIE-pre-v2.0.1-history.bundle
git bundle list-heads PhiRIE-pre-v2.0.1-history.bundle
git fetch ./PhiRIE-pre-v2.0.1-history.bundle refs/heads/NAME
git switch --detach FETCH_HEAD
```

## Reproduce the release checks

```bash
git clone --recurse-submodules git@github.com:RunyiYang/PhiRIE.git
cd PhiRIE
uv sync --project envs/control --locked --group regression
envs/control/.venv/bin/python tools/release/verify.py
envs/control/.venv/bin/ruff check phiroom tests/test_module_interfaces.py tools/release
SIMANY_CAMPAIGN_PY="$PWD/envs/control/.venv/bin/python" bash run/campaign/final_preflight.sh
MUJOCO_GL=egl envs/control/.venv/bin/python -m pytest -q tests --basetemp=.tmp/pytest-regression
uv build
```

The complete source ZIP includes the pinned PhiView source; GitHub's automatically
generated parent-only archives do not. The lightweight wheel does not install GPU
backends, checkpoints, datasets or the full source configuration tree. The optional
regression group pins the OpenPI client to an immutable Git commit and uses CPU Torch.

The broad local regression run additionally uses the existing pilot video at
`videos/pilot_a29cccc784.mp4`, a byte-verified Menagerie Panda/Robotiq closure,
and the control interpreter as `.venv/bin/python` for legacy subprocess launchers.
These local runtime/test inputs are excluded from the source archive. Native robot
runtime tests and integrations requiring unavailable original frozen paths are
explicitly skipped; the production provenance checks remain unchanged.

## Validation and remaining work

Exact test counts, exit codes, source commits, skipped checks and asset hashes are
recorded in the attached `validation.json`, `release-manifest.json`, `SHA256SUMS`,
and validation logs. The final readiness report accompanies the release.

This is a code maintenance release. No new GPU model generation, learned-policy
benchmark, browser review, or full paper experiment campaign was run for it.
Previously published generator results retain their original 116/128 evaluated
cohort and 12 missing inputs; see [the original package](../generator_comparison/20260915/).
Scientific completion remains governed by [FINAL_EXPERIMENTS.md](../../FINAL_EXPERIMENTS.md).
Historical frozen experiment configurations and receipts keep their recorded paths;
new experiments require fresh resolved configurations and the documented admission gates.

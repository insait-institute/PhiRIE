# PhiRIE v2.0.1 — INSAIT release

The codebase and project page are maintained at
https://github.com/insait-institute/PhiRIE on the single `main` branch.
The project page is https://insait-institute.github.io/PhiRIE/.
Author order, affiliations, and corresponding-author attribution are provided in
[CITATION.cff](../../CITATION.cff).

## Contents

- Complete code snapshot from `RunyiYang/PhiRIE` commit
  `f41a2e8c2a9f396ea34128264a805430eac5c22f`.
- All 207 PhiView upstream source files from
  `2b7a01505d84d09e925c0d8b77ef61bfd7151b8f`, bundled with their existing license
  and per-file provenance. Cloning no longer requires access to a separate repo.
- Organization repository links, author metadata and citation file.
- Portable Python wheel and source distribution plus full-source archives,
  validation receipts, release manifest, and SHA-256 checksums.

The original `RunyiYang/PhiRIE` release tags are unchanged. This organization
release is a new snapshot cut from `RunyiYang/PhiRIE` commit
`f41a2e8c2a9f396ea34128264a805430eac5c22f` with PhysicalView
`2b7a01505d84d09e925c0d8b77ef61bfd7151b8f`.

## Run and verify

```bash
git clone https://github.com/insait-institute/PhiRIE.git
cd PhiRIE
uv sync --project envs/control --locked
uv run --project envs/control --locked python tools/release/verify.py
bash run/phiroom.sh modules
uv build
```

Models, GPU runtimes, weights, datasets, and external third-party backends retain
their documented setup requirements. The lightweight wheel installs the portable
CLI; use the full source checkout for configurations, viewers, and GPU pipelines.
No new training, inference campaign, robot-policy benchmark, or scientific result
is asserted by this packaging release.

See the release's `VALIDATION.json` and `RELEASE_REPORT.md` for checks run on this
snapshot, historical evidence, unmeasured behavior, and exact artifact identities.

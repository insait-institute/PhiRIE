# Task 04 — Metric Scale and Robot-Base Alignment

**Priority:** P0  
**Suggested owner:** calibration / robotics geometry engineer  
**Depends on:** Tasks 01–03  
**Blocks:** Tasks 06–09, 17–18

## Objective
Estimate and validate `T_base<-scan` plus metric scale with quantified uncertainty. A scene that looks correct but is mis-scaled or misaligned must fail certification before policy evaluation.

## Existing code
- `agents/recon/metricize.py`
- `agents/recon/align_to_traj.py`
- `run/run_droid_recon.sh`
- robot/camera models under `robo/rigs/`

## Supported alignment modes
1. Fiducial or ChArUco visible in scan and calibrated robot camera.
2. Phone depth / AR odometry plus surveyed robot-base points.
3. Known robot/table dimensions as scale constraints.
4. DROID FK trajectory and reconstructed wrist-camera centers via robust Sim(3) alignment.

## Outputs
- `agents/recon/robot_align.py`
- `agents/recon/alignment_report.py`
- `configs/calibration/*.yaml`
- `tests/test_robot_alignment_synthetic.py`

Report scale factor and CI, rotation/translation residuals, reprojection residual, floor-normal error, table-height error, and held-out marker/trajectory error.

## Implementation steps
1. Implement robust weighted Sim(3)/SE(3) solvers with RANSAC or robust loss.
2. Keep calibration observations separate from evaluation observations.
3. Transform splat, mesh, objects, cameras, and physics consistently; test link/COM conventions.
4. Add degeneracy detection for collinear markers or insufficient trajectory baseline.
5. Define hard thresholds for build rejection and softer features for the task certificate.
6. Generate a visual overlay and numerical report for every phone room.

## Tests
- Synthetic random transforms recover scale <1%, translation <5 mm, rotation <0.5 deg under nominal noise.
- Injected outliers are rejected.
- Forward then inverse transform round-trips all scene modalities.
- DROID alignment reproduces existing robot-base results.

## Acceptance criteria
- [ ] No rollout begins without an alignment report.
- [ ] Held-out alignment residual is reported, not fitted residual alone.
- [ ] Scale/alignment ablations can be generated by controlled perturbation.

Metric phone deployment, reachability validity, and robot-frame ablation rows.

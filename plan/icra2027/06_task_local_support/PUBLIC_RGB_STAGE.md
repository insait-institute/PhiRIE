# Prospective public RGB reconstruction stage

The stage preserves the six-scene, three-condition, 72-query population. It reads only public JPEGs and frozen query declarations. Legacy depth, extrinsics, initialization point clouds and splats are excluded because their original construction provenance is unsuitable for this experiment. Nine condition/query source-frame pairs are absent; their absence remains explicit.

The fixed frame rule uses all available frames up to 48, otherwise 48 equally spaced lexicographic indices. An existing query anchor replaces the last sampled frame when necessary; an absent anchor is never injected. The engineering smoke uses the smallest positive clean-frame count, breaking ties by frozen scene order: behavior_task0023 clean, six frames. The scientific pilot remains behavior_task0020 clean/mild/severe. All source and configuration identities must be sealed before execution.

The runner invokes the existing Omega, DA3 metricization, scene conversion and 15,000-step Gaussian producers with seed zero and separate condition paths. Model failure terminates the condition without fallback. The output manifest retains logs and executed commands, including typed nonzero producer failures. A reconstruction PASS verifies finite predicted geometry, camera/frame schemas and the Gaussian producer split; it does not imply a full twin, metric query grounding, physical stability, an independent held-out rendering score, or a task-local result. Feature rows remain zero at this stage.

Use a dedicated DA3 source/overlay with user site disabled; existing Python environments are immutable. Runtime records contain exact source commits, interpreter/overlay bytes, package metadata fingerprints, canonical Gaussian runtime identity and checkpoint content hashes. E0 weight resources use `kind: model_weights_content`, so the E0 hash is the content hash, rather than its generic large-checkpoint metadata fingerprint. Subsequent execution checks retain the sealed content identity and reject weight size/mtime drift.

CPU verification: `python -m pytest -q tests/test_e6_public_reconstruction.py tests/test_task_support_real_inputs.py tests/test_task_support_smoke.py`. Exact E0: `SIMANY_PY=/group/worldcept/code/SimAny/.venv/bin/python bash run/icra2027/preflight.sh --smoke` with inherited `SIMANY_EVIDENCE_ROOT` unset for synthetic fixtures.

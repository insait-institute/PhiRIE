# Optional engineering evidence display

`robo.eval.paper_pipeline` accepts an optional `engineering_appendix` mapping in
its existing `preliminary_audit` configuration. The existing required
`audited_artifacts` and all main-table treatment rosters remain unchanged.

Each optional source has `path`, `sha256`, and a `completion_audit` identity.

- `trellis2_geometry`: the sealed `trellis2_geometry/geometry.json` from the
  standalone fixed mesh pilot, with `independent_geometry_completion_audit.json`.
  The formatter preserves all planned jobs, matched conditioning, null unmatched
  geometry and null appearance. It displays only producer aggregate CD/F1 and
  collapse counts. Native Gaussian/full-twin/paper/headline flags stay false.
- `e4_planning`: `planned_coverage/handoff.json`, `independent_qa.json`, and an
  additional `publication_receipt` identity. The formatter authenticates the
  coverage manifest/seal, fixed canonical task/reset identities, null policy
  telemetry, original qualifier evidence and source E0. It displays fixed planned
  cells, prerequisite-checked records, eligible cells and recorded rollouts.
  Endpoint-unavailable/construction-rejected records are not simulator or physical tests.
  Policy success remains unavailable. It never creates a rollout ledger.

The separate, compact tables are `trellis2_geometry_engineering.tex` and
`compact_applicability_engineering.tex`. They describe different units and do not
form a combined benchmark. Source JSON/CSV copies, exact field paths in the claim
ledger, and completion receipt hashes are archived by the same existing pipeline.
They enable no scientific superiority or manipulation claim. The source receipts
certify integrity/reproducibility, not success of those claims.

Actual source paths for the reviewed engineering pilots:

- `outputs/icra2027/20260905-a8ab431-v1/trellis2_geometry/geometry.json`
- `outputs/icra2027/20260905-a8ab431-v1/independent_geometry_completion_audit.json`
- `outputs/icra2027/20260905-e890df8-v1/planned_coverage/handoff.json`
- `outputs/icra2027/20260905-e890df8-v1/independent_qa.json`
- `outputs/icra2027/20260905-e890df8-v1/publication_receipt.json`

No final config, paper table or paper text is generated by adding this support.
After review, freeze a new exact-source configuration with these content hashes
and run the existing paper pipeline. Preserve prior paper freezes unchanged.

Smoke and negative tests:

```bash
python -m pytest -q tests/test_paper_pipeline_audit.py tests/test_paper_engineering_appendix.py
```

For a compact paper, `omit_unmeasured_object_table: true` is permitted only when
all declared object-method metric fields are null. It leaves the room table in
`object_factorization_main.tex` and writes the original empty object-table
skeleton separately to `object_fidelity_unmeasured_skeleton.tex`. All eight
fidelity source rows remain in JSON/CSV, and provenance records the omission.
Any measured value, including zero, rejects the omission request. The default
combined-table behavior and the E2 evaluator/roster are unchanged.
